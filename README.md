# SC803 自动热点 (BuleWifi)

本项目旨在为腾讯/阅文**「口袋阅2代」SC803**（展讯平台，Android 8.1.0 / API 27，免 Root）开发一款自动热点伴侣应用，作为 iPad mini / Mac 的随身 4G 移动热点。

---

## 阶段规划概览

- [x] **Milestone 1（已完成并通过实测）**：蓝牙 ACL 连接与断开事件探测（Bluetooth Event Probe），验证普通安装 APK 在 Android 8.1 上接收系统蓝牙广播的稳定性。
  - *实测记录*：MacBook Air 连接（`CONNECTED`）与断开（`DISCONNECTED`）广播 100% 成功捕获。
- [x] **Milestone 2（已完成并通过实测）**：无障碍服务（AccessibilityService）模拟点击系统设置，验证免 Root 切换飞行模式、蓝牙与 WLAN 热点。
  - *实测记录*：退出飞行模式、进入飞行模式、开启蓝牙、开启 WLAN 热点、关闭 WLAN 热点全部通过真机实测（耗时 < 1 秒）！
- [x] **Milestone 3（当前版本）**：目标设备白名单过滤（支持选择已配对目标设备，锁定 MAC 地址或监听全部）。
- [x] **Milestone 4（当前版本）**：串行自动化状态机串联（含 4G 蜂窝数据就绪等待、60 秒断开宽限期重连防抖、自动关热点进飞行并恢复蓝牙）。
- [ ] **Milestone 5**：开机自启与异常容错优化。

## 核心自动化业务流水线（Milestone 4）

```text
日常待机状态：
飞行模式 ON + 蓝牙 ON + 热点/Wi-Fi OFF + 蜂窝网络 OFF (极度省电)
```

### 1. 目标连接触发流水线
```text
目标设备蓝牙 CONNECTED（已配对白名单过滤，支持多选）
       ↓
自动唤醒屏幕（WakeLock 硬件点亮，解决息屏无法渲染无障碍控件问题）
       ↓
取消可能存在的关机倒计时
       ↓
退出飞行模式（恢复蜂窝基带）
       ↓
等待 4G/LTE 移动网络数据就绪
       ↓
通过无障碍自动开启 WLAN 热点
       ↓
进入状态：ONLINE（目标设备可上网）
       ↓
自动熄灭屏幕休眠（DeviceAdmin 极速灭屏，静默省电）
```

### 2. 目标断开退出流水线
```text
目标设备蓝牙 DISCONNECTED
       ↓
检查是否仍有其他白名单目标设备在线（多设备保持机制）
       ↓
所有目标设备均断开时，启动 60 秒断开宽限倒计时（状态栏实时更新）
       ↓
若在 60 秒内任意目标重新连接：取消倒计时，无缝恢复 ONLINE
       ↓
若 60 秒超时仍未连接：
       ↓
自动唤醒屏幕
       ↓
关闭 WLAN 热点
       ↓
开启飞行模式
       ↓
单独重新唤醒蓝牙
       ↓
回到待机状态：飞行 ON + 蓝牙 ON + 热点 OFF
       ↓
自动熄灭屏幕休眠
```

## 实机使用与验证指引

### 1. 安装最新 APK
在 GitHub 仓库的 **Actions** 页面下载最新的 `SC803-AutoHotspot-debug` 产物，执行：
```bash
adb install -r app-debug.apk
```

### 2. 初始化配置（首次使用）
1. 确保已开启 **「SC803 自动热点辅助服务」** 无障碍权限；
2. 确保 SC803 系统「设置」->「安全」->「屏幕锁定」设置为 **「无」**（随身热点最佳配置，无滑动/密码阻挡）；
3. （推荐）点击 **`[🔒 开启自动熄屏权限]`**，在弹出系统窗口点击「激活」，开启操作完成后自动灭屏；
4. 点击 **`[选择目标蓝牙]`**：在弹出的多选列表中勾选你的 MacBook Air、iPad mini 等设备；
5. 点击 **`[自动控制: 已停止 (点击启动)]`**：开启全自动控制模式；
6. 点击测试按钮 **`[开启飞行]`**，再点击 **`[开启蓝牙]`**，让 SC803 进入预期的省电待机状态（飞行模式 ON + 蓝牙 ON），即可锁屏装包！

### 3. 全自动端到端验证
1. **连接测试**：
   - 使用目标设备（Mac 或 iPad）连接 SC803 的蓝牙；
   - 观察 SC803：自动化状态机自动触发 -> 退出飞行模式 -> 4G 信号恢复 -> 自动开启 WLAN 热点 -> 状态进入 `ONLINE`；
   - 目标设备此时可通过 Wi-Fi 连接 SC803 的热点上网！
2. **断开与防抖测试**：
   - 目标设备主动断开蓝牙连接；
   - 观察 SC803：状态机进入 `宽限断开中 (剩余 60 秒)` 倒计时；
   - **防抖验证**：在倒计时结束前重新连上蓝牙，观察是否立即取消关机并保持热点；
   - **关机验证**：断开蓝牙静置等待 60 秒，倒计时归零后，观察是否自动关闭热点、开启飞行模式并重新打开蓝牙，完成自动省电闭环！
